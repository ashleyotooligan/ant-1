# Capture your own app screenshots

The release includes reproducible figures. Use this sequence if you want genuine browser screenshots of the console on your computer.

1. Double-click `ANT-1.html` and maximise your browser window.
2. Open **Run archive** and choose the seed-17 navigation reference.
3. It reconstructs the run and pauses. Capture the **Observatory** with your operating system's screenshot tool.
4. Switch to **Neural interface** without resuming. Capture the activity and motor readout.
5. Open **Experiments** for the protocol catalogue.
6. Open **External tasks → Run comparison** for the optional market view. Keep the synthetic-data label in the image.

Save images under `assets/screenshots/`, with filenames such as `observatory-seed17-tick2400.png`. In the README, use relative Markdown image links. Record the version, seed, tick and data mode in the caption. Keep the figure captions intact when showing existing figures.

On Windows, **Win+Shift+S** captures a region. On macOS, **Shift+Command+4** captures a region. A full-width screenshot around 1440–1600 pixels is suitable for GitHub.

Screenshots should show the software's actual state. Do not replace equity values, neuron counts, experimental results, or status labels with invented numbers.
