# Changelog

## 0.1.0 — 2026-09-12

Initial experimental release.

- One simulated ant, a deterministic arena, idealised bilateral sensing and food-return behaviour.
- A 32-unit synthetic recurrent controller with a transparent steering prior and plastic action-value readout.
- Observation console, neural interface, seven experiment protocols and replayable reference runs.
- Matched-seed benchmark with all 84 run outcomes included.
- Standalone offline HTML, modular source and command-line experiment tools.
- Optional market interface with delayed paper execution, explicit costs, synthetic fixtures and comparison policies.
- Tests for interventions, reproducibility, cash accounting and future-data isolation.
- Direct-rendered model figures, a replay animation, methods, model card and upload guide.

Known limitation: live browser screenshots were not captured in the build environment. Included documentation figures are generated directly from the simulation renderer and labeled accordingly.
